# 管理页面布局检查（2026-10-23）

本次检查使用本地运行的 Farhelm 与 ego-browser。改动限于前端布局、按钮样式和现有设备选择器的呈现方式，未修改接口或权限规则。

## 修正内容

- 访问控制搜索框移除额外顶部间距，并与创建按钮统一高度；高级授权按钮组增加明确间距和换行空间。
- 用户、角色、用户组、API Token、修改密码及证书表单使用网格间距，移除标签和输入框叠加的外边距。
- API Token 创建、保存、复制操作使用主按钮，撤销确认使用危险按钮；修改密码的取消、退出使用次按钮。
- 命令表单目标设备使用带标题的完整字段；设备选择器展开后的搜索、分组过滤去除顶部错位。
- 设备详情采集周期与保存按钮对齐：浏览器实测修正前顶部相差 7px，修正后顶部及高度一致。
- 侧栏收起时，修改密码使用 40×40px 图标入口，保留可访问名称和悬停提示，避免文字断行。
