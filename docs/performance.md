# 性能验证

## 设备列表状态恢复（2026-10-22）

当前标签页使用 `sessionStorage` 保存设备列表的页码、每页数量、搜索词和设备组筛选。浏览器刷新后先校验 `/me`，仅在用户、角色、有效设备范围和权限一致时恢复；权限集合顺序变化不会清空导航。详情页刷新后返回列表也保留原位置。输入搜索词即保存，来不及等待 300 ms 防抖就刷新也能恢复；服务端将越界页码修正到末页后，保存修正值。

退出、登录失效、账号切换、有效权限或设备范围变化会清理旧状态，并取消待发搜索、清空跨页勾选、重置为每页 50 台的首页。权限在页面关闭期间变化时同样不会沿用旧筛选。恢复过程不会先请求默认首页或旧范围；网络暂时失败时保留状态等待重新校验。损坏、越界或不可用的浏览器存储不会阻止登录。跨页勾选和设备数据不持久化；标签页之间不主动同步状态。

本地前端 227 项测试、类型检查与生产构建通过；新增验证覆盖状态恢复、授权变化、存储异常、待发搜索、末页修正和退出清理。隔离数据库中 120 台设备的真实 Chromium 分页回归和详情导航回归通过，包含刷新后的列表位置、详情返回、账号切换及在线/刷新时权限变化。上述结果不替代 CI 或生产验收。

## 任务概况聚合（2026-10-22）

设备总览每 10 秒请求 `GET /api/v1/tasks/summary`，只返回 `{v, active, unknown}`。统计全部可见任务：`active` 包含 QUEUED/SENT/ACCEPTED/RUNNING，`unknown` 是 UNKNOWN；不再限于最近 500 条。详情和其他页面不轮询此接口。

统计与任务历史共用权限条件，设备范围与“仅本人/允许查看他人”限制同时生效；API Token 继续使用与所有者权限相交后的范围。查询只扫描未解决任务索引，不读取命令、结果或事件。权限变化清除旧计数，迟到请求不能覆盖新会话；统计失败不影响设备操作。

## 轻量设备选择器（2026-10-22）

历史筛选、命令执行、设备组成员、用户/用户组授权和 API Token 授权改用按需打开的设备选择器。每页 25 台，搜索停顿 300 ms 或按 Enter 后请求服务端；可按组筛选。多选跨页、跨筛选保留，当前页全选不会覆盖其他页；“仅看已选”按页解析 ID，支持逐台移除不可见或失效的选项，不会根据当前页自动删掉成员。读取失败保留原选择，修改组名等操作仍携带完整成员 ID。

`GET /api/v1/device-options` 始终分页，支持 `page/limit/q/group`，返回 `{v, devices, page}`。设备项只有 `id/name/connection_kind/revoked_at`，不投影网络、健康、磁盘或连接凭据。`purpose=exec` 额外要求 `tasks.execute`，只列出未撤销的 Agent 设备；离线 Agent 仍可选择并按原任务 TTL 规则等待。`ids` 可传最多 50 个 ID 的 JSON 数组，查询时仍与当前授权范围相交，不回显范围外设备信息。所有后续写操作继续校验权限和设备引用。

App 不再为历史、命令或授权面板请求完整 `/devices`；历史名称使用列表返回的名称快照。权限变化会重建选择器并清除旧历史筛选、列表与命令表单；迟到响应不会覆盖新查询。旧完整设备接口继续为现有外部客户端保留。

验证覆盖轻量字段、分页与搜索、受限 Token、执行候选权限、撤销即时生效、跨页选择上限、迟到响应、选项失败保留成员，以及真实浏览器中的设备组和 API Token 保存结果。

本地服务端 192 项、前端 205 项、协议契约 382 项测试通过，服务端/前端类型检查和构建通过。120 台设备的浏览器分页与选择器验证、任务统计与详情导航验证通过；已检查桌面和手机界面。未将这些结果视为 CI 或生产验收。

## 设备分页和服务端筛选（2026-10-22）

设备总览默认每页 50 台，可选 25/100 台。搜索名称、ID、Agent 版本、IP 和组名在服务端进行，输入停顿 300 ms 或按 Enter 后生效；组筛选与搜索叠加。切换筛选条件或每页数量回到首页；定时刷新仍在当前页。详情返回保留页码、筛选与选择。

`GET /api/v1/devices` 不带查询参数仍返回完整列表。传入 `page`、`limit`、`q`、`group` 中任一参数启用分页，默认第 1 页、每页 50 台，最多 100 台。`group=__ungrouped__` 表示未分组；`q` 为字面包含匹配，`%`、`_` 不作为通配符。响应新增 `page: {number, limit, total, pages, visible_total, groups}`：`total` 是筛选后的数量，`visible_total` 是授权范围总数，`groups` 是整个授权范围的组名选项（不含成员列表）。页码超出末页会回到末页，无结果时页码为 1。结果按创建时间和 ID 稳定排序；这是实时分页，设备增删时边界可能变化，不是快照。

权限、搜索和分组条件先作用于 SQL，再对本页 ID 投影网络、健康与磁盘缓存；不会为其他页设备计算这些状态。索引 `devices_list_order` 支持创建时间与 ID 排序。在线指标明确显示“本页 Agent 在线”。

全选与取消全选只作用于当前页，选择按设备 ID 跨页、跨筛选保留，并显示不在当前页的数量。批量标签提交冻结的全部选中 ID，一次最多 1000 台；服务端仍原子校验权限和设备引用，失效设备不会被静默跳过。清空选择、退出或权限范围变化清除选择。设备组编辑通过轻量分页选择器按需读取选项，保留其他页的成员。

回归入口：服务端 `device-list.test.ts`、前端 `device-pagination.test.ts`、契约测试和 `npm run test:pagination`。浏览器验证使用隔离数据库中的 120 台设备，不写入本地实际设备数据。

本地验证：服务端 190 项、前端 197 项、契约 380 项测试通过；服务端与前端构建通过。分页和设备详情导航两组真实 Chromium 验证通过，包含跨页批量标签的数据库结果、授权范围、刷新、详情返回和移动端无横向溢出。以上不替代 CI 或生产验收。

## 按页面刷新（2026-10-22）

前台标签页每 10 秒校验身份并刷新当前页面数据。设备总览刷新当前页设备与任务概况；设备详情使用 `GET /api/v1/devices/:id`，只查询当前授权设备，不拉取全量设备、任务概况或触发磁盘采集。单设备接口复用列表的状态投影和权限规则。

任务、审计和终端历史定时刷新各自列表；设备名称来自历史响应，设备选择器打开后按需查询。访问控制/API Token 页同样按需加载设备选项；系统设置与升级页不再由主页面拉取无关设备列表，其自身配置与进度刷新保持不变。权限变化清除设备缓存，迟到的详情响应不能覆盖其他设备或退出后的状态。

验证覆盖单设备与列表投影一致、授权范围实时变化、前端请求数量、设置页不拉取无关列表、详情不定时采集磁盘、并发请求合并与迟到响应隔离。

## 设备列表批量读取（2026-10-22）

设备列表先在 SQL 中限制用户可见范围，再批量读取分组、网络策略、健康结果和有效连接凭据。同一请求复用状态；不跨请求缓存权限或连接状态，撤销和配置变化在下一次请求生效。不带查询参数时保持原有完整列表响应。

本地 macOS、Node 24.21.0、临时 SQLite 数据库，真实 Fastify `/api/v1/devices` handler（inject，无网络传输），静态离线 Agent 设备。预热后取 7 次请求中位数：

| 设备数 | 优化前 SQL prepare 调用 | 优化后 | 优化前中位耗时 | 优化后 |
| --- | ---: | ---: | ---: | ---: |
| 50 | 1,255 | 13 | 5.03 ms | 0.53 ms |
| 500 | 12,505 | 13 | 47.70 ms | 2.46 ms |
| 1000 | 25,005 | 13 | 95.29 ms | 4.76 ms |

网络策略首次应用可能仍需逐设备持久化，这是原有行为；表中为无需修改策略的读取。数据不代表在线终端并发、生产硬件或端到端延迟。

`apps/server/test/device-list.test.ts` 对 500 台设备设置查询数量回归门禁，并验证授权范围变化、凭据不泄漏、分组/IP/SSH/网络策略投影及撤销状态。服务端 181 项测试、协议契约 370 项、服务端类型检查通过。

## 请求路径中的同步阻塞（2026-10-22）

- 网页/SSH 登录、用户创建、密码修改/重置改用异步 scrypt：最多 2 个计算、16 个等待请求，超限返回 429。异步计算后重新检查当前身份、密码和授权；数据库事务中不等待密码计算。启动初始化和内部测试用户播种仍使用同步密码函数。
- Agent 升级下载使用异步分块文件读取和异步 SHA-256；校验后的内存快照不受随后文件修改影响，最多 2 个下载持有快照直到响应结束（每包上限 64 MiB）。下载期间撤销或到期的设备凭据不会被继续放行。
- 静态资源文件读取改用异步 I/O。SQLite FULL 提交、录制持久化以及发行包导入/上传等其他路径未在此次改造中整体异步化。

服务端 183 项全量测试通过；额外并发认证测试验证密码计算期间健康请求仍可完成，以及排队时被禁用的用户无法获得会话。异步密码测试覆盖兼容旧哈希、队列限额及恢复；文件测试覆盖损坏、截断和返回快照的不可变性。服务端类型检查通过。
