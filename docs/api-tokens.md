# 通用 API、API Token 与 Skill

管理员登录网页，在左侧 **API Token** 中创建、查看、编辑和撤销令牌；同页可下载 OpenAPI 文档与配套 Skill。普通用户暂未开放令牌管理，后端已按用户归属建模。

## 创建和使用

填写用途名称，选择权限、具体设备或全部设备、有效期（最长 366 天）。默认只勾选查看设备，设备默认不选，有效期 30 天。设备组只用于批量选择当前设备，保存后是具体设备 ID，不跟随标签变化。全部设备包含以后新增设备，但仍受所属用户当前设备权限约束。

完整 Token 只在创建成功时返回一次，前端以密码框展示并支持复制，关闭即清除。服务器只保存 SHA-256 摘要与不可用于认证的前缀。若创建时网络断开，先刷新列表核实；已创建但未拿到密钥的令牌应撤销后重新创建。

调用地址是**网页管理入口**加 `/api/v1`，支持平台已有的 HTTP/HTTPS 配置，不要使用仅接收 Agent 的 HTTPS 端口。请求通过 `Authorization: Bearer fh_api_…` 鉴权；禁止将令牌放 URL。无需网页登录或周期性刷新短期登录会话。

平台继续提供相同的任务、权限和审计逻辑。接口支持查询设备、健康和网络状态，配置健康检查与网络探测，提交/读取/取消命令任务，建立终端和读取会话录制。命令任务目前依赖 Agent，交互终端支持 Agent 与 SSH。

OpenAPI 3.1：`GET /api/v1/openapi.json`，需有效登录会话或 API Token。各接口权限、参数、请求/响应定义随服务端发布。首版不对 Token 开放账号管理、系统设置、设备凭据管理或令牌管理接口。

## 授权和生命周期

- 每枚 Token 固定归属于创建者，不能通过请求体指定或更换所属用户。管理员可查看、撤销全部 Token，只能编辑自己的 Token。
- 有效权限与设备范围分别取 **Token 授权 ∩ 所属用户当前授权**。即使创建者是管理员，也不能绕过 Token 权限和设备范围。用户角色、用户组或设备授权变化会在下一次调用及终端权限检查时生效。
- `tasks.read`、`recordings.read`、`audit.read` 默认查看所属用户本人的记录。查看他人记录需显式勾选对应 `.read_all` 和 `.read`；审计权限不包含取消他人任务或关闭他人终端。
- 限定设备的 Token 不能通过“本人审计”读到范围外设备，且不能读取无设备归属的平台审计。空设备范围不授予任何设备权限。
- 账号禁用或处于强制改密状态时，Token 不可使用；恢复账号后，未过期、未撤销的 Token 可按当前授权使用。网页退出登录或完成个人密码修改不会自动删除独立 API Token。
- 修改采用 `revision` 防止覆盖并发变更；到期或已撤销的 Token 不可续用，需要新建。撤销不可恢复。修改权限会重新检查已打开的终端；撤销立即触发终端检查，到期也会在终端输入和周期检查时生效。
- 已受理的命令任务保留原状态，Token 到期或撤销不会撤回已提交操作。如需停止任务，请在任务中心单独取消。
- 每个账号最多 100 枚未过期且未撤销令牌；创建限流每用户每分钟 10 次，调用限流每 Token 每分钟 300 次、同属用户每分钟 1000 次，并保留现有来源与操作级限流。

## 审计

创建、修改、撤销以及已识别 Token 的 API 请求均记录审计。请求记录包含所属用户、Token 名称和 ID、来源地址、请求 ID、方法、路由和 HTTP 结果码；原有业务操作审计继续保存命令、设备与任务等信息。查询请求也有记录，已撤销或到期密钥的尝试可追踪。审计不记录 Authorization、完整密钥或请求原始 body。

终端仍由平台统一录制，任务输出沿用现有存储。异步 Agent 事件保留原事件来源，可通过创建时的任务/终端 ID 关联 Token 调用。

## Skill 接入

从 API Token 页面下载 `farhelm-api-skill.tar.gz`，解压后将 `farhelm-api` 目录放入支持 Agent Skills 的 AI 客户端技能目录。仓库源文件位于 `skills/farhelm-api/`。客户端需要 Python 3.10+、脚本执行权限及到平台的网络连接；不需要 MCP 服务。

通过客户端的安全配置提供以下环境变量：

| 变量                     | 用途                                              |
| ------------------------ | ------------------------------------------------- |
| `FARHELM_URL`            | 平台网页管理地址，不带 `/api/v1`                  |
| `FARHELM_API_TOKEN_FILE` | 保存完整 Token 的文件路径，建议只允许当前用户读取 |
| `FARHELM_API_TOKEN`      | 不使用文件时可由客户端凭据配置注入                |
| `FARHELM_CA_FILE`        | 可选，私有 CA 的 PEM 文件；公共 CA 无需设置       |

随后使用 `python3 <技能目录>/scripts/farhelm.py me` 验证有效权限，`devices` 查询设备。Skill 含 API 参考、任务幂等提交、有限等待、分页和录制读取说明。Python 客户端拒绝重定向转发凭据，不跳过 TLS 验证，不自动重试写操作，不将 Token 放命令行参数。

后续向普通用户开放时，应调整令牌管理入口授权和列表可见范围，继续复用用户归属、实时权限交集、设备限制和审计，不新增独立的管理员旁路。

真实 Edge 中验证创建、设备组选择、编辑权限和有效期、一次性密钥显示、撤销、审计，以及 Skill/OpenAPI 文件下载；检查了 390px 手机布局。下载内容与仓库源文件逐字节一致，Skill 校验通过，Python 客户端实际完成 HTTPS 查询与幂等任务提交。Docker 构建上下文验证了运行时契约和 Skill 资源复制，一键安装脚本通过语法检查。本轮未重新运行完整 Linux Agent E2E 或完整生产镜像部署，不将本地通过视为生产验收。
