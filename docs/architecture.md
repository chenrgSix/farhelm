# 当前架构与开发里程碑

最新交接文档优先于 legacy。最小纵向链路是 Vue 登录 → 单体 API 授权 → SQLite 任务 → Agent 主动 WSS → Agent journal/outbox → 非 root 单账号 Exec → HTTPS 输出对象 → 服务端事件/任务/审计事务 → ACK。不存在独立 exec.request 快捷执行系统。

## 主要决策

1. 保留 Rust、Tokio、TypeScript、Fastify、Vue 3、SQLite 单体，不加 MQ/Redis/Kubernetes
2. Ed25519 证明私钥持有、一次性注册、签名上下文域隔离、短期访问 token、TLS 验证和撤销
3. 至少一次投递 + 两端持久化幂等；外部副作用不能声称 exactly-once，执行歧义进入 UNKNOWN
4. 任务/事件/输出分别定义 durable ACK，文件和数据库不共用事务，优先允许孤儿文件而非已确认缺失对象
5. 输出完整性明确受限，超限/审计失败停止；预览截断不等于原始丢失
6. 用户明确选择自己配置的单 Linux 账号，已说明共享 UID 边界，保留 ExecutionBackend 扩展点；不擅自创建双账号或特权启动器

早期架构审查中的双 UID 建议保留为历史讨论，当前生效的是 ADR-006。SQLite 使用 Node 24 内置 node:sqlite（仍会发出实验性 API 提示），把同步事务保持短小；这是单机 MVP，不保证多实例与500台高负载。

## P0 通信与身份

当前实现范围：TLS/WSS、注册恢复、心跳/重连、撤销、平台登录、设备页、版本化契约。通过条件及未跑的公网/NAT场景见 acceptance/p0.md 与 test-report.md。

## P1 单设备命令闭环

当前实现范围：角色及设备范围、幂等命令、持久化 journal/outbox、单并发、输出/审计、TTL、取消/超时、崩溃 UNKNOWN。进程组不能保证 setsid 后代全部清理；不把这种限制伪装为强隔离。

## P2 终端与录像（基础实现，完整验收待补）

Agent PTY + xterm.js + 中央会话网关强制时序录制，先持久化后转发，审计不可用不得继续会话。按平台用户/session独立归属，记录可见输出和窗口事件，不采集隐藏密码按键。

基础实现及实际验证见 [交互终端](terminal.md)。现阶段断流关闭，不自动恢复会话或重放输入；不宣称完整 P2 生产验收通过。

## P3 私网健康与回退（基础实现）

已实现逐设备 VPN 优先、公网备用和仅内网策略，Agent 持久化与 SSH 新连接选路，真实 EasyTier P2P / 中继观测，权限和会话录制沿用。EasyTier 仍由用户独立部署。当前以完整 Agent 控制/数据连接选路，公网备用是否独立取决于实际路由；独立数据通道和公网流量配额仍未实现。配置和验证见 [网络策略](network-routes.md)。

## P4 业务模板与调度（未实现）

版本化批准模板、文件/脚本、部门设备组、1台金丝雀再每批5台、计划发生次数幂等、失败详情。业务用户不能变成自由Shell。

## P5 上线与可选扩展（未实现）

按需 SSH Proxy、签名升级、对象存储/PostgreSQL；必须实做恢复、许可证/SBOM、安全、容量、50–500台负载及洪峰验证，不默认叠加全部扩展。
