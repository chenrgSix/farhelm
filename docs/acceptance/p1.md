### P1：单条授权 Exec 的可靠闭环

交付：管理员从 Web 对授权设备执行单条命令；任务、结果、stdout/stderr、身份和授权审计；本地 outbox、HTTPS 输出对象、结果补传；TTL/取消/超时/输出与并发限制。

验收：
- `uptime`、有权限的有限日志读取及非零退出命令显示原始 argv、cwd、stdout/stderr、退出码、平台用户、设备与 task ID
- HTTP 请求重试、同 task ID 重发三次、丢 accepted/finished ACK 均不新增一次执行；同 ID 不同 payload 拒绝
- 在 accepted 提交前后、RUNNING 提交前后、spawn 后、输出封存后、finished 事务前后、服务端 commit/ACK 间逐点注入崩溃，验证预期恢复或 UNKNOWN，不盲目重跑
- 任务运行时断控制连接，进程按规则继续、结果重连补传；事件重复/乱序不能导致状态回退或审计伪完整
- 过期未执行任务不上线补跑；取消请求与真实结束区分。超时命令含 fork/setsid 后代，按声明的进程隔离能力验证清理；不能确认时不得伪报已取消
- stdout/stderr 同时大量输出、非法 UTF-8、管道尾部、低磁盘/写失败、超配额有有界内存和明确审计失败；无静默丢弃；服务重启仍能读全部已确认对象
- 根据用户最新单账号决定：不再要求同UID密钥隔离，必须如实标明共享权限；业务/审计员/跨设备用户不能调用任意 Exec，不允许客户端选择任意UID。强隔离属于后续用户确认项
- 恢复备份并核对任务、审计和输出索引；全量 lint/typecheck/unit/integration/e2e 记录通过、失败及未运行项
