源码、npm/Cargo锁文件、版本化JSON Schema、跨语言fixture、Linux进程与协议测试、真实Rust到Fastify端到端测试、Vue控制台、本地CA启动脚本、离线备份脚本、ADR及P0–P5验收规划。最终构建和运行证据见test-report.md及test-evidence/。

## 与早期草案不同

- 以最新交接为准，不包含HOST_TLOG、auditd、旁路SSH审计或EasyTierManager
- 单次Exec就是统一任务管线，不保留第二套绕过journal的执行消息
- 用户自行配置单Linux账号；已说明同UID安全边界，未擅自创建系统账号或安装特权助手
- PTY/时序录像属于P2，EasyTier私网健康/数据回退属于P3，均未实现
- 不保证通用Shell exactly-once，不保证setsid逃逸后代全部终止；歧义结果UNKNOWN不自动重跑
- 控制帧有界，输出走独立HTTPS接口，审计不完整显式呈现

## 发布与许可

项目源码发布许可由用户决定。本次只交付给用户，没有向公共仓库或生产环境发布。npm与Cargo依赖由各自许可证约束；锁文件固定本次解析版本，正式商用前仍需完整依赖许可证/SBOM和漏洞审查。
