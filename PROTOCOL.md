# Fleet protocol v1 implementation contract

All HTTPS/WSS; timestamps Unix milliseconds integers. JSON UTF-8, snake_case. All API bodies use v:1 except user login. HTTP headers Bearer auth (never query tokens). WSS JSON envelope: {v:1,type:string,body:object}; maximum 64KiB. Agent identity public_key is raw 32-byte Ed25519 in base64; signatures 64-byte base64. SHA256 lowercase hex.

## Identity
- POST /api/agent/challenge {v:1,purpose:"enroll"|"auth",public_key:string,enrollment_token?:string,device_id?:string} -> {v:1,challenge_id,signing_payload,expires_at}. signing_payload is base64 of exact bytes to sign. Decoded bytes are UTF-8 fields joined by newline with terminal newline: fleet-v1, server_instance, purpose, challenge_id, nonce(base64 32 random bytes), public_key, device_id or empty, SHA256(enrollment_token) or empty, expires_at decimal. Server constructs bytes; Agent checks purpose/key/device/token digest/expiry in returned payload before signing.
- POST /api/agent/enroll {v:1,challenge_id,signature,name} -> {v:1,device_id}. Challenge stores enrollment token binding. Redeemed same enrollment + same key with fresh proof recovers original ID even after token redeemed (until token expiry; afterward key recovery auth supported).
- POST /api/agent/auth {v:1,challenge_id,signature} -> {v:1,device_id,access_token,expires_at}. Auth challenge may use public_key without device_id to recover ID after enrollment response loss; registered key is unique. Access token opaque random, server persists hash + device + expiry + scope, default 5 minutes.
- WSS /agent/ws Authorization Bearer device access token. agent.hello {agent_version}; agent.heartbeat {agent_version}. Server expires/ revokes token and closes connection; newest connection owns sends. Heartbeat every 2 seconds dev / configured production.

## Task and events
Task object exact fields: {task_id,device_id,actor_id,action:"exec",argv:string[],cwd:string,created_at:integer,expires_at:integer,timeout_ms:integer,max_output_bytes:integer,payload_hash:string}. payload_hash is SHA256 of immutable task fields with canonical key-order JSON excluding payload_hash (RFC8785-compatible only these constrained values). Rust serde_json object sorting / TS recursively sorted keys equivalent. task.assign body is Task. task.cancel {task_id}. No exec.request shortcut.

Agent task event envelope type task.event body: {event_id,task_id,seq:integer,kind:"accepted"|"started"|"finished",at:integer,payload:object}. event_id UUID. accepted payload {}; started payload {}; finished payload {status:"SUCCEEDED"|"FAILED"|"TIMED_OUT"|"CANCELLED"|"EXPIRED"|"UNKNOWN",exit_code:integer|null,reason:string|null,audit_complete:boolean,stdout:{sha256,size},stderr:{sha256,size},started_at:integer|null,finished_at:integer,cleanup:"process_group"|"unconfirmed"|"not_started"}. For UNKNOWN crash missing artifacts, stdout/stderr may be null and audit_complete=false. Terminal no-execution results may use empty objects or null. Sequential events persist atomically with journal and outbox; seq monotonic from 1; finished after accepted may be seq2 for expired/cancelled before starting. Server event.ack {event_id,task_id,seq} only after transaction and required artifacts. Same ID same bytes re-ACK, different content reject. Each task identity permanently tombstoned. Server task state monotonic, only apply contiguous events.

## Output
PUT /api/agent/tasks/:task_id/artifacts/:sha256 Authorization device token, content-type application/octet-stream, raw bytes; task-bound device identity check; max 1 MiB/object, task max_output_bytes governs combined streams; verifies hash, fsync temporary, rename, fsync directory then DB index -> {sha256,size}. Server artifact IDs content hash plus task owner; API GET /api/v1/tasks/:task_id/output/:stream returns raw bytes after user auth only and writes view audit. Metadata GET task includes result references.

## User API
POST /api/v1/login {username,password} -> {access_token,user:{id,username,role,device_scope}}. Bearer user sessions in memory UI only, server session hashes. roles admin/ops/business/auditor; admin all scope, ops restricted or *, business no arbitrary exec, auditor read only. Initial admin explicitly bootstrapped via env FLEET_ADMIN_USER + FLEET_ADMIN_PASSWORD, no defaults.
GET /api/v1/me -> user. GET /api/v1/devices -> {devices:[{id,name,control_online,private_data_reachable:null,business_healthy:null,last_seen,revoked_at,agent_version}]}.
POST /api/v1/enrollment-tokens {name?,ttl_seconds?:integer} -> {enrollment_token,expires_at} admin only; POST /api/v1/devices/:id/revoke -> {ok:true} admin.
POST /api/v1/commands Idempotency-Key header {device_id,argv,cwd,timeout_ms,max_output_bytes,ttl_seconds} -> {task_id,status}; key bound actor + normalized request hash, conflicts 409. Server supplies actor, expiry, hash. GET /api/v1/tasks -> {tasks:[...]}; GET /api/v1/tasks/:id -> task detail with result; POST /api/v1/tasks/:id/cancel -> {ok:true,status}. GET /api/v1/audit -> {audit:[...]} role/scope filtered.

## Config
Server env FLEET_HOST (127.0.0.1), FLEET_PORT(8443), FLEET_DATA_DIR, FLEET_TLS_CERT, FLEET_TLS_KEY, FLEET_ADMIN_USER/PASSWORD. Optional FLEET_TEST_MODE=1 permits narrowly scoped fault injection only loopback. Export buildServer(config) app/store/close helpers for tests.
Agent env FLEET_SERVER_URL=https://localhost:8443, FLEET_CA_CERT=path (custom trusted CA, never skip verify), FLEET_STATE_DIR, FLEET_ENROLLMENT_TOKEN, FLEET_DEVICE_NAME, FLEET_EXECUTION_BACKEND=same-uid|disabled. Default same-uid per explicit user choice; account is configured by user, agent refuses root. No identity isolation is claimed; arbitrary commands can access same-UID Agent secrets/state. No production privilege creation. FLEET_HEARTBEAT_MS optional, FLEET_TEST_FAULT optional, only with FLEET_TEST_MODE=1, crash point.
